## Engineering OS

Run all commands via `node scripts/engineering-os.mjs <command>` from this project
root (auto-targets this repo). Read `.engineering-os/LESSONS_LEARNED.md` before
pickup. Every reported change must use repository-relative `path:line` locations
and command evidence. For a qualifying failure, create both an incident and a
linked lesson. Do not close the task until the lesson has an enforceable
prevention mechanism and its validation evidence. Before another agent takes
ownership, create a handoff record; the next owner runs `accept-handoff`. Never
write Engineering OS state outside the project Git root.
